Nexa Studio
===========

A responsive, customizable classic WordPress theme for small businesses and
creative services. It includes an editable business homepage, blog layouts,
navigation menus, global design controls, WooCommerce support, a widget
sidebar, and optional About and Contact page templates.

Requirements
------------

- WordPress 6.0 or newer
- PHP 7.4 or newer

Installation
------------

1. Upload the `my-first-theme` folder to `wp-content/themes/`, or zip the folder
   and install it from Appearance > Themes > Add New > Upload Theme.
2. Activate Nexa Studio from Appearance > Themes.
3. Set your Site Title and Tagline in Settings > General. Upload a logo from
   Appearance > Customize > Site Identity.
4. Assign links to the Primary Menu and Footer Menu under Appearance > Menus.

To change the header and footer brand text, use Appearance > Customize >
Homepage Content > Brand name. A custom logo replaces the brand text in the
header.

Homepage
--------

Open Appearance > Customize > Homepage Content to change the hero, about,
six services, latest-posts, About page values and contact call-to-action text
and links. Set a static homepage under Settings > Reading to use the included
business homepage. To show posts on a separate journal page, create a page and
select it as the Posts page in Settings > Reading.

Theme design
------------

Use Appearance > Customize > Theme Design to choose the global primary, accent,
background and text colors; adjust the content width; choose a header layout;
and select a system font style. The block editor includes matching theme
colors, fluid type presets and wide-layout controls through `theme.json`.

About page
----------

Create or edit a page titled About Us with the `about-us` slug. The theme
applies the designed About page automatically. You can also select the About
Us template when creating a page with a different slug. Edit the story in the
block editor and the lead, story heading and values under Appearance >
Customize > Homepage Content.

Contact page
------------

Create a page, choose the Contact template in the page editor, then publish it.
The contact form sends messages to the site administrator email in Settings >
General. WordPress mail delivery depends on the site's hosting configuration;
configure an SMTP plugin if messages are not delivered.

Blog and content
----------------

Add posts and featured images using Posts > Add New. The theme includes post,
page, archive, search, 404 and comment layouts. Add widgets to Appearance >
Widgets > Blog Sidebar; it appears on archive pages.

WooCommerce
-----------

Install and activate WooCommerce to enable the theme's product gallery, shop
image sizes, product grid support and responsive shop, product, cart and
checkout styles. Payment methods, tax, shipping, privacy and store compliance
are configured separately in WooCommerce.
