My First Theme
==============

A responsive, customizable classic WordPress theme for small businesses and
creative services. It includes an editable business homepage, blog layouts,
navigation menus, a widget sidebar, and an optional contact page template.

Requirements
------------

- WordPress 6.0 or newer
- PHP 7.4 or newer

Installation
------------

1. Upload the `my-first-theme` folder to `wp-content/themes/`, or zip the folder
   and install it from Appearance > Themes > Add New > Upload Theme.
2. Activate My First Theme from Appearance > Themes.
3. Set your Site Title and Tagline in Settings > General. Upload a logo from
   Appearance > Customize > Site Identity.
4. Assign links to the Primary Menu and Footer Menu under Appearance > Menus.

Homepage
--------

Open Appearance > Customize > Homepage Content to change the hero, about,
services, latest-posts, About page values and contact call-to-action text and
links. Set a static homepage under Settings > Reading to use the included
business homepage. To show posts on a separate journal page, create a page and
select it as the Posts page in Settings > Reading.

About page
----------

Create a page titled About Us with the `about-us` slug. The theme applies the
designed About page automatically. You can also select the About Us template
when creating a page with a different slug. Edit the page content in the block
editor and the lead, story heading and values under Appearance > Customize >
Homepage Content.

Contact page
------------

Create a page, choose the Contact template in the page editor, then publish it.
The contact form sends messages to the site administrator email in Settings >
General. WordPress mail delivery depends on the site's hosting configuration;
configure an SMTP plugin if messages are not delivered.

Blog and content
----------------

Add posts and featured images using Posts > Add New. The theme includes post,
page, archive, search, 404 and comment layouts. Add widgets to Appearance >
Widgets > Blog Sidebar; it appears on archive pages.
